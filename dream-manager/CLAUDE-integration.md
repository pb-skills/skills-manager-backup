## Dreams — Agent Improvement Proposals

- Follow `.claude/skills/dream-manager/SKILL.md` when identifying, reviewing, or updating improvement proposals.
- Store proposals in the central queue `C:\ai\memories\dreams\dreams.md` (shared by all projects). Read existing entries and merge related ideas before adding new ones.
- Capture useful opportunities without interrupting the user's active task; consolidate during task-end reflection when appropriate.
- At a recognised new-session boundary, briefly offer up to three relevant pending dreams (scoped to this project or cross-project), unless the user prefers otherwise. Never block the current task.
- Dreams are suggestions, not permissions or autonomous goals. Never install tools, change systems, request access, or run experiments beyond approved scope.
- After user-authorised experiments, report measured results; move proven lessons into the right `C:\ai\memories\categories\` file (usually `successes.md` or `procedures.md`) via `memory-optimizer` and archive completed dreams.
